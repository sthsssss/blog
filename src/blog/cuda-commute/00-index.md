CUDA는 NVIDIA GPU에서 범용 계산을 수행하기 위한 병렬 컴퓨팅 플랫폼입니다. 애플리케이션은 CPU에서 실행되는 코드와 GPU에서 실행되는 코드를 함께 사용합니다. CPU는 입력을 준비하고 작업을 제출하며, GPU는 많은 데이터에 적용할 계산을 병렬로 수행합니다.

이 시리즈에서는 CUDA가 제공하는 실행 모델을 설명합니다. 먼저 그래픽 처리용 하드웨어를 일반 계산에 사용하게 된 배경을 살펴봅니다. 이어서 CUDA C++ 프로그램을 컴파일하고 실행하는 과정을 설명한 다음, 스레드의 작업 분배, 메모리 액세스, 동기화 및 성능 측정으로 범위를 확장합니다.

## CUDA가 해결하는 문제

큰 배열의 각 원소에 같은 계산을 적용하는 프로그램을 고려해 보세요. CPU에서는 반복문으로 원소를 순회할 수 있습니다. 원소 사이에 의존성이 없다면 여러 원소를 동시에 계산할 수도 있습니다. GPU는 이러한 병렬 작업을 높은 처리량으로 수행하도록 설계되어 있습니다.

GPU를 사용하려면 계산식만으로는 충분하지 않습니다. 어느 코드가 GPU에서 실행되는지, 각 실행 인스턴스가 어떤 원소를 처리하는지, 입력과 결과를 어디에 저장하는지를 지정해야 합니다. CUDA는 이 작업을 표현하는 프로그래밍 모델과 실행 API를 제공합니다.

CUDA가 등장하기 전에도 GPU를 일반 계산에 사용하는 연구는 진행되고 있었습니다. 다만 개발자는 계산을 그래픽스 API가 받아들이는 형태로 표현해야 했습니다. CUDA의 중요한 변화는 이 제약을 제거하고, 그래픽 장치를 계산 플랫폼으로 사용할 수 있는 개발 환경을 제공한 데 있습니다.

이 변화는 NVIDIA의 사업 범위와도 연결됩니다. 게임과 시각화에 사용하던 GPU를 과학·공학 계산에 공급하려면 계산용 하드웨어뿐 아니라 개발자가 사용할 수 있는 소프트웨어가 필요했습니다. 시리즈의 첫 문서에서는 당시 공시와 연구 논문을 통해 이 관계를 살펴봅니다.

## 사전 요구 사항과 예제 범위

C++의 함수, 포인터, 배열 및 반복문을 알고 있다고 가정합니다. GPU 프로그래밍 경험은 필요하지 않습니다. CUDA 용어는 해당 구성 요소를 처음 사용하는 위치에서 설명합니다.

예제는 CUDA C++을 사용합니다. 역사적 설명에서는 초기 CUDA가 C 확장으로 소개되었다는 점을 구분하며, 코드에는 현재의 CUDA C++ 표기를 사용합니다. CUDA Toolkit 12.6과 GTX 1070을 예제 검증 환경으로 삼습니다. 최신 도구가 모든 이전 GPU를 지원한다는 가정은 하지 않습니다.

본문의 코드 조각은 해당 절의 동작에 집중합니다. 필요한 헤더, 오류 처리, 자원 정리 및 결과 비교를 포함한 전체 프로그램은 [예제 소스](/downloads/cuda-commute/examples.cu)에서 확인할 수 있습니다. 부록에서는 실제 실행으로 확인한 항목과 설명에만 사용한 항목을 구분합니다.

## 문서를 읽은 뒤

시리즈를 마치면 CUDA 프로그램이 컴파일된 뒤 GPU에서 실행되는 경로를 설명하고, 각 스레드의 메모리 액세스 범위를 확인할 수 있습니다. 또한 결과의 정확성, 커널 실행 시간 및 애플리케이션 전체 처리 시간을 서로 구분할 수 있습니다.

첫 문서에서는 이러한 실행 모델이 등장한 배경을 설명합니다. PTX가 필요한 이유를 이해하려면, 먼저 GPU 하드웨어를 일반 계산에 사용하려던 개발자와 NVIDIA가 각각 어떤 문제를 해결해야 했는지 살펴봐야 합니다.
